# Battle Hamsters 맵 에디터 — 아키텍처

## 개요

웹 기반 2D 맵 에디터. Battle Hamsters 게임의 맵 JSON 포맷을 직접 읽고 쓴다.
게임 클라이언트(Phaser 3)와 동일한 렌더링 환경을 사용하여, 에디터에서 보이는 것과 게임에서 보이는 것의 인지적 차이를 최소화한다.

## 기술 스택

| 항목 | 선택 | 이유 |
|---|---|---|
| 렌더링 | Phaser 3.80 | 게임 클라이언트와 동일 |
| 빌드 | Vite 5 | 게임 클라이언트와 동일 |
| 언어 | TypeScript 5.4 | 게임 클라이언트와 동일 |
| UI 프레임워크 | 없음 (Phaser만 사용) | 게임 클라이언트와 동일 |

## 입력/출력 포맷

- 입력/출력: `docs/technical/data-formats.md`에 정의된 맵 JSON 포맷을 그대로 사용
- 버전 필드: `version: 1`
- 본게임 `packages/shared/maps/*.json` 과 완전 호환

## 핵심 도메인 모델

### 편집 가능한 요소 (Editor Elements)

| 카테고리 | 프리미티브 | 시각 표현 | 조작 방식 |
|---|---|---|---|
| Collision | `floor` | 녹색 사각형 | 드래그 배치 + 핸들 리사이즈 |
| Collision | `one_way_platform` | 청록색 사각형 (점선 테두리) | 드래그 배치 + 핸들 리사이즈 |
| Collision | `solid_wall` | 회색 세로 막대 | 드래그 배치 + 핸들 리사이즈 |
| Hazards | `fall_zone` | 빨강 반투명 사각형 | 드래그 배치 + 핸들 리사이즈 |
| Hazards | `instant_kill_hazard` | 주황 반투명 사각형 | 드래그 배치 + 핸들 리사이즈 |
| Spawn | `spawnPoints` | 파란 원 | 드래그 배치 + 이동 |
| Weapons | `weaponSpawns` | 보라 다이아몬드 | 드래그 배치 + 이동 |
| Items | `itemSpawns` | 노랑 별 | 드래그 배치 + 이동 |

### 비-편집 가능한 영역 (표시만)

| 영역 | 시각 표현 |
|---|---|
| `visualBounds` | 흰 점선 사각형 |
| `gameplayBounds` | 노랑 점선 사각형 |
| `deathBounds` | 빨강 점선 사각형 |

이 영역들은 속성 패널에서 수치로만 편집한다.

## 에디터 동작

### 배치 흐름
1. Toolbar에서 요소 타입 선택
2. 캔버스 빈 공간에 클릭(또는 드래그)으로 배치
3. 기본 크기/위치로 생성
4. 배치 후 자동으로 선택 상태 → 속성 패널에 값 표시
5. 드래그로 이동, 엣지 핸들로 리사이즈

### 선택/편집
- 클릭: 단일 선택
- Delete 키: 선택 요소 삭제
- 속성 패널: 선택된 요소의 모든 필드 실시간 편집

### 카메라
- 마우스 휠: 줌 인/아웃 (0.25x ~ 4x)
- 우클릭 드래그 또는 Space+드래그: 팬
- Home 키: 원래 뷰로 리셋

### 그리드
- 기본 40px 그리드 표시
- 스냅: 토글 가능 (기본 켜짐)
- 그리드 크기: 설정에서 변경 가능

### 파일 I/O
- Export: 맵 데이터를 JSON 파일로 다운로드
- Import: JSON 파일을 드래그앤드롭 또는 파일 선택으로 로드
- 출력 포맷은 본게임 맵 JSON 포맷과 완전 호환

## 비목표 (1차)

- 배경/terrain/decoration 에셋 편집 (본게임에서 먼저 결정 필요)
- undo/redo (후순위)
- 멀티플레이어 실시간 협업 편집
- 맵 밸런스 시뮬레이션
- 커스텀 에셋 업로드
